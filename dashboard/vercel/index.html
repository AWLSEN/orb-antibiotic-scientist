An AI scientist, running on cloud, designing new medicine for a drug-resistant infection.

Methicillin-resistant staph (MRSA) kills over a million people a year, and most big drug companies stopped making new antibiotics. This is an autonomous AI chemist trying to help — proposing new molecules, testing them computationally, and saving the ones that might work.

how it works

It sleeps when it's not working. Wakes up instantly when it is.

Like an app minimised on your phone, the agent is parked to disk when it has nothing to do — no memory used, no bill running. When a new task arrives, it's restored in under a second. This is how it runs 24/7 at the cost of a few cents a day.

what it's made so far

Novel drug candidates, each checked by twelve independent tests.

Every molecule has to pass a chemistry sanity check, a physics-based binding simulation, a toxicity screen, a novelty check against all known drugs, and a final adversarial review. Only candidates that clear all twelve get published.

A note on what this is and isn't.

These molecules are computational hypotheses. They have not been synthesised, tested in bacteria, or reviewed by any regulator. Think of them as starting points: the agent is doing the 95% of medicinal-chemistry work that happens before any wet lab opens a vial.

If you run a lab that works on antibiotic development and something here looks interesting, reach out — the agent is generating these openly so they can be picked up.
